## Environment notes
- Engine tests need no database. Django tests need PostgreSQL. The owner creates `.env` (`uv run python scripts/init_env.py`); my file tools cannot touch `.env*`. With no `.env`: `uv run python scripts/init_env.py --output <scratch>/test.env`, then `set -a; . <scratch>/test.env; set +a; docker compose -p attainmenttest --env-file <scratch>/test.env up -d db`. The scratch env file is per session: make a new one (or ask before removing a volume). The old `attainmenttest-db-1` container may still exist; its passwords come from an old scratch file, so a fresh session usually needs a fresh project name.
- Optional test environment: `DB_CONTAINER=<db container name>` enables the backup and restore tests (`apps/tenancy/tests/test_ops.py`); `WEASYPRINT_DLL_DIRECTORIES="C:\Program Files\GTK3-Runtime Win64\bin"` enables the PDF tests on Windows (GTK3 runtime installed with `winget install tschoonj.GTKForWindows`; the Docker image has Pango); `uv run playwright install chromium` enables `tests/e2e`.
- Memory: a full test run (about 15 minutes) plus Docker can exhaust RAM on this machine and the session may stop the run. Run one pytest at a time, in the background, with nothing else heavy open. Do not restart a run that was stopped for memory unless asked.
- Bash heredocs with quotes and `sed` with nested quotes often fail to parse here: use the Write tool for files and short Python snippets for edits. A Python edit inside a heredoc turns `\\t` into `\t`: use raw strings for JavaScript in tests.
- Before each commit: `uv run ruff format .` then `uv run ruff check .`, `uv run mypy engine`, `uv run python manage.py makemigrations --check`. Ruff line length 100. Generated migrations need `tenant_rls(...)` lines added by hand. Run ruff on the branch you commit on: a missed line failed CI once.
- CI runs on pushes to `main` and PRs to `main` only (`gh workflow run ci.yml --ref <branch>` for others); it installs the Playwright browser and takes up to 45 minutes. GitHub user: sohanroy676. For stacked PRs retarget each to `main` before merging; merge with merge commits so tags stay on the history.
