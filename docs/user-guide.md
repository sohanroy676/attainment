# User guide

For lecturers, coordinators, heads of department, IQAC staff, the exam branch and the principal. It follows the order of the work: enter marks, submit them, look at the result, get it approved and signed, print the report.

You only ever type **marks** (and, for IQAC, the indirect value and targets). Levels, counts, percentages and attainment are worked out for you, and every one of them can be explained.

## 1. Signing in
- Open the college's address and sign in with the username and password the administrator gave you. Passwords need at least 10 characters. Five wrong tries lock the username for 15 minutes.
- After 30 minutes without activity you are signed out; whatever you saved is kept.
- The first page lists your roles. **My tasks** shows what is waiting for you, with a link to each item.

## 2. Entering marks (lecturer, coordinator)
You enter marks for the sections you teach. Marks are kept **per question part** (1a, 1b, ...), not per question.

Each box means something different:
| You type | Meaning |
|---|---|
| a number, including `0` | the student answered; the mark is that number |
| `AB` | absent |
| `-` | not attempted |
| `WH`, `EX`, `NA` | withheld, exempted, not applicable |
| nothing | nothing entered yet (blank is **not** the same as 0) |

A mark above the part's maximum is refused. Two ways to enter:
1. **On the page.** Open the assessment for your section; type into the boxes and press **Save**. If someone else changed a box after you opened the page you are told, and nothing is overwritten silently.
2. **From Excel.** *Download the sheet* (roll numbers and the question columns are already in place), fill it in, and *Upload a filled sheet*. You see a preview first. If **any** row has a problem the whole file is refused, so a half-imported sheet never happens. Save the file in Excel before uploading; a formula that was never calculated is rejected with its cell named.

For the semester exam the exam branch enters marks by script number and maps scripts to students.

Every change is kept (who, when, old and new value). After you submit, changing a mark needs a reason.

## 3. Submitting
When a section's marks are complete, **submit** the assessment. The coordinator **accepts** it or **returns** it with a reason. Accepted marks cannot be edited. Wait for the coordinator before expecting a final result: until every section is accepted, the result is marked **Provisional**.

## 4. Reading the result
Open the course result from **My tasks** (or the link your coordinator sends).
- **Provisional** (with a red notice and a list of what is missing) means something is still missing: marks not entered, a target not set, an indirect value not entered, a paper not set up. Fix the item and the result recalculates by itself.
- Each number is a link: **Explain** shows the question parts, pass counts, the denominator used, the method and engine version and the input fingerprint behind it.
- A `*` beside a percentage means the shown figure sits on a level boundary that the exact figure does not reach (the unrounded value is on the Explain page).
- **Indirect** values are *entered, not measured*, until surveys arrive in a later version.
- **Gaps** lists the COs under target and the weakest question parts, to start an observation.

## 5. Pass marks that differ from 60%
By default a part is passed at 60% of its maximum. If a paper really needs a different pass mark for a part, a person with the paper-editing right (the coordinator) proposes an override **with a reason**, and IQAC or the head of department approves it. Overrides can only be made before the result is approved. Every override is listed on the printed report.

## 6. Approving and signing
Coordinator → **review**; head of department → **approve** (this locks the marks); principal → **sign** (this freezes the result: nobody can alter it afterwards). To change a signed result, someone with the right *reopens* it with a reason; that starts a new cycle and the earlier signed result stays on record. For a batch (all courses of a programme and batch), IQAC prepares, the HoD approves and the principal signs in the same way.

## 7. Reports
From a course result choose **Reports**: CO sheet per assessment, course analysis (theory or lab), CO-PO table, Action Taken Report, and an explanation appendix. Each can be viewed on screen, downloaded as PDF, and the main tables as Excel. The batch report (with the three-batch chart) is under the batch result. Every page carries a footer with the college, programme, batch, course, method version, engine version, run id, status, time and a fingerprint; an unfinished result is watermarked **PROVISIONAL**. IQAC and admin can also download the NBA course list.

## 8. Observations and the action plan
On the quality page write what you saw in the results (the gaps page offers a draft) and what will be done next time. Plans carry forward: next year you record **what was done**, with the date and proof (PDF, PNG or JPEG, up to 5 MB each). They appear in the Action Taken Report.

## 9. What you cannot do (by design)
- See another college's data, or another section's marks if you only teach yours.
- Type a calculated number (level, count, percentage).
- Edit approved or signed marks without a reopening and a reason.

If something looks wrong, use **Explain** first; then tell your coordinator or IQAC with the run id from the page footer.
